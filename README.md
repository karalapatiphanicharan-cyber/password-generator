🔐 SecurePass — Password Generator & Security Analyzer
A full-stack, production-ready cybersecurity web application built with the MERN stack. 
Generate strong passwords with 4 modes (Standard, Passphrase, Banking Grade, WiFi), 
analyze password strength in real-time with entropy calculation and crack-time estimation, 
save history locally, and visualize your security trends with interactive charts.
✨ Features:
• Smart password generator with 4 generation modes
• Real-time strength analysis with entropy & crack time
• QR code generation for easy password transfer
• Password history saved in localStorage (no backend needed)
• Security analytics dashboard with Recharts
• Glassmorphism dark UI with Framer Motion animations
• Keyboard shortcut (Ctrl+G) to regenerate instantly
• Fully offline — works without a server
🛠️ Tech Stack:
Frontend: React 18, Vite, Tailwind CSS, Framer Motion, Recharts, React Router DOM
Backend: Node.js, Express.js, MongoDB, JWT, bcryptjs, Helmet, Rate Limiting
Deployment: Vercel (frontend) + Render (backend) + MongoDB Atlas
